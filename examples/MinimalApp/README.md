# Minimal Unity app

1. Create an empty Unity 2021.3+ project.
2. Package Manager, "Add package from git URL": `https://github.com/watchtowerobservability/watchtower-unity.git`.
3. Import the "Minimal" sample, add `WatchtowerBootstrap` to any GameObject, fill in the key and endpoint.
4. Press Play. An error log and an exception appear in Watchtower within about 5 seconds.
